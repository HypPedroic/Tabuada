# Tabuada

Projeto front-end simples para exercícios de tabuada.

## Sobre
- Pequena aplicação em HTML, CSS e JavaScript para demonstrar uma interface estática.

## Como usar
1. Abra o arquivo `index.html` no seu navegador (duplo clique ou arraste para a janela do navegador).
2. Ou use uma extensão como *Live Server* no VS Code para visualizar e atualizar automaticamente.

## Estrutura do projeto
- `index.html` — página principal
- `src/javascript/script.js` — código JavaScript
- `src/styles/styles.css` — estilos CSS

## Contribuição
- Faça alterações locais, teste abrindo `index.html` e envie pull requests se desejar colaborar.
